      Your identity

      An identity is a key made here, in your browser. Nobody hands it out and nobody can take it away - and nobody can give it back if you lose it.

      This first web client keeps your key in memory only. Save the key file if you want to use this identity again - and keep it like a password. Vault support (UN-RFC 0007) comes next.
